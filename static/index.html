chemfig · mhchem · TikZ 语法速查与避坑指南

        
      

      

        

          
1. chemfig 8 方位角度时钟图

          

            
            
键线式常用 [:30] 与 [:-30] 交替绘制标准 120° 锯齿链。

          

        

        

          
2. 常见实战防踩坑准则

          
    
            
  • 隐式碳顶点切换键型要加括号：从折线隐式碳顶点连立体楔形键时，写成 -[:135](<:[2]OH)，不要连写 -[:135]<:[2]OH。
    • 
            
  • 苯环朝向与画法：**6(------) 为内切圆圈，*6(-=-=-=) 为凯库勒交替双键；前加 [:30] 让苯环上下尖顶竖向摆放。
    • 
            
  • 竖排多行主链防重叠：甘油三酯等带上下羰基的多行结构，给竖向主链设置键长倍率 -[6,2.2]。
    • 
            
  • 反应箭头中写数学符号：在 \schemestart 的 \arrow{->[上][下]} 内，温度 \Delta 等数学符号需写为 [$\Delta$]；而纯 \ce{->[\Delta]} 可直接识别。
    • 
          

        

        

          
3. mhchem 与 chemfig 组合速查

          

            
\ce{H2SO4} → 硫酸自动上下标

            
\ce{SO4^{2-}} → 带多电荷离子

            
\ce{A + B <=>[条件] C ^} → 可逆与气体

            
\chemfig{R-NH-R^{\prime}} → 通式基团

            
\chemfig{H-[:0,1.4,,,dotted]O} → 虚线氢键

            
\charge{90=\:}{O} → 孤对电子点
